# Security & Responsible Use Policy

## Scope

Auracelle Charlie is a static HTML research instrument. It runs entirely in the browser with no backend, no user accounts, no network calls to external services, and no server-side data storage. Session data is stored only in browser `localStorage` and exported locally by the researcher.

## Responsible Use

This instrument is designed for **academic research, doctoral examination, and institutional demonstration** purposes. Use of the platform to simulate or plan actual cyberattacks, disinformation operations, or coercive actions against real organizations is outside the intended scope and is not sanctioned.

The MITRE ATT&CK technique mappings in Tab ⑨ are used as a **citable academic taxonomy** for adversarial governance simulation — they are not operational attack guidance.

## Data Privacy

- No personal data is transmitted to any external server
- Session exports (JSON/CSV) are saved to the researcher's local machine only
- The instrument does not use cookies or tracking
